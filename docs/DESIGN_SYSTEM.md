# Sistema visual

Fuente auditada: bootstrap.custom.scss usa negro/rojo/naranja; no representa la identidad de Castillo. El propietario aportó posteriormente el símbolo PNG original, que se utiliza sin redibujar.

Tokens en website/src/styles/tokens.css: navy #081327 y oro #DCB574 obtenidos del PNG; el dorado es aproximado por tratarse de un raster. Blanco #FFFFFF como superficie principal, gris frío #F3F6F9 para separar secciones, texto #102238 y secundario #526174. Se retiraron el beige y los marrones de la primera propuesta. Ver BRAND_ASSETS.md.

Tipografía: Manrope variable para titulares, Inter variable para cuerpo y navegación. Fuentes servidas localmente. Sin cursivas. Contenedor máximo 1240px; capacidades en dos columnas, una en móvil; márgenes fluidos y radios de 3–5px. Botones navy sobre claro y blancos sobre oscuro. Oro en detalles y texto grande sobre navy; no usarlo como texto pequeño sobre blanco. Foco visible y movimiento reducido respetado.

Referencia de criterio cromático: https://carbondesignsystem.com/elements/color/overview/ . Se toma la separación de roles y superficies; no se copia la paleta de IBM. El sistema de color de Castillo parte de su propio símbolo.
