# Castillo v2 — Design system direction

## Brand premise
Preserve and elevate the existing Castillo identity.

Existing assets:
- Castillo logo: square frame with three ascending gold bars.
- Deep navy background.
- Warm gold accent.
- White / off-white contrast.

Do not redesign the logo unless explicitly requested.

## Visual personality
Keywords:
- precise
- architectural
- calm
- premium
- analytical
- modern
- executive
- technically credible

Avoid:
- generic SaaS gradients
- neon cyberpunk
- AI brains / robots
- glassmorphism everywhere
- excessive cards
- stock consultant photography
- fake dashboards
- over-animated interactions

## Color
Exact brand values must be extracted from original logo/assets where available.

Initial working token families:
- Navy 950: near-black blue
- Navy 900: primary dark surface
- Gold 500: primary accent
- Gold 300: subtle line/highlight
- Ivory 50: warm page background
- White: high-contrast content
- Ink 900: primary text on light
- Slate 500/600: secondary text

Gold must be used sparingly. It is an accent and navigation/precision cue, not a fill color for large areas.

## Layout
- editorial grid
- max content width approximately 1180–1280px
- generous section spacing
- asymmetric compositions allowed
- alternate light and dark sections
- avoid endless card grids
- use fine rules and aligned baselines to communicate financial precision

## Hero
Dark navy.
Large editorial headline.
Logo / brand visible but not oversized.
One concise supporting paragraph.
One primary CTA, one optional secondary link.
A subtle architectural/data visual, not a decorative illustration.

## Graphic language
Derive motifs from the logo:
- three vertical bars
- thin gold rules
- stepped progression
- modular columns
- data-to-decision flow
- connected nodes / system architecture
- ledger/grid references used abstractly

## Typography
Choose a high-quality, license-safe webfont or system stack.
Target contrast:
- Display: authoritative, editorial sans or restrained grotesk
- Body: highly readable sans
- Optional mono only for tiny technical labels, never as the dominant look

Do not use more than 2 font families.

## Motion
- 150–450ms
- subtle entry transitions
- scroll-linked effects only if they add meaning
- diagram flows may animate gently
- respect prefers-reduced-motion
- no parallax gimmicks

## Components
- Header / nav
- Hero
- Service narrative rows
- Capability matrix
- Data & AI feature section
- Process / methodology timeline
- Founder credibility section
- Azhum product bridge
- CTA band
- Footer
- Optional architecture diagram
- Optional FAQ

## Accessibility
- WCAG AA minimum
- keyboard navigation
- strong visible focus
- semantic landmarks
- no essential meaning conveyed only by color
- reduced motion support
- comfortable line length and minimum body size
- responsive from small mobile to large desktop

## Responsive behavior
Mobile is not a compressed desktop.
On mobile:
- simplify diagrams
- reduce decorative lines
- keep CTA visible
- avoid horizontally scrolling service content
- maintain generous breathing room

## Quality check
The site should feel credible to a CFO and equally credible when forwarded to CIO/IT.
It should not feel like a personal résumé site or a generic AI agency template.
