# Modelo de contenido

`website/src/data/content.ts` contiene identidad, canales de contacto, capacidades y pasos. Cada capacidad presenta problema, intervención y entregable. Las páginas editoriales usan componentes y layout comunes. El idioma del documento es es; futura traducción requiere contenido completo, rutas y hreflang, no traducción automática parcial.

Contacto público: exclusivamente LinkedIn, https://www.linkedin.com/in/gersoncastillolorenzo/. CTAs principales abren el perfil; /contacto/ contextualiza la conversación y ofrece el mismo canal. El correo personal no se incluye en HTML, datos estructurados ni configuración de contenido público. Sin WhatsApp ni teléfono hasta que el propietario disponga de un número profesional. Azhum: https://azhum.com.

Un formulario futuro requeriría recepción y reenvío en servidor, destinatario en configuración privada, validación y protección antiabuso. No incluir el destinatario ni credenciales en código cliente. No implementado ni necesario para la estrategia de contacto actual.
